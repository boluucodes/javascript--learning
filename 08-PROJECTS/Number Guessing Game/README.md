NUMBER GUESSING GAME

**Description**
A number guessing web application build with HTML, CSS and JAVASCRIPT

**PREVIEW**


## FEATURES
- Accepts an input.
- The program validates the input.
- The input is checked against the randomly generated number in the program.
- The result is returned.
- User feedback to assist users when they guess correctly or close to the answer
- clean ui

## TECH STACK
- HTML5
- CSS
- JAVASCRIPT

## HOW IT WORKS
- User put in a number in the input field.
- The input is stored and probed by the program to check if it between 1-100.
- The program checks if the number is the same as or close to the randomly generated number.
- If the number = generated number, the user wins
- If the user is slightly close to the generated number, the programs gives the user directions to guess correctly.
- After a correct guess, the game resets.
