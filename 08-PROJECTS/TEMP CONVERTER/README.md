## MARKDOWN
TEMPERATURE CONVERTER

**DESCRIPTION**
A simple temperature converter application built with HTML, CSS AND JAVASCRIPT.

**PREVIEW**

## LOGIC
- CREATE AN INPUT FIELD TO TAKE IN NUMBERS(TEMP IN DEG PRIMARILY).
- THE INPUT TYPE SHOULD TO CHANGEABLE, e.g., the input can be 51 deg celsius or 51F or 51k
- conversely, the output should be changeable, e.g., to deg or F or Kelvin.
- a btn that triggers the conversion.
- A reset btn
- maybe, this time, add some smooth animations using simple css and js.

## FEATURES
- Accepts numerical inputs
- Validates the input
- processes the conversion using mathematical operations
- returns answer with the desired unit
- The page is reset after the reset btn is clicked.
- repeat
